# Homebrew-Jumpshell

JumpShell is a cross-platform .NET 10 console app for managing and opening saved remote connections.

## Installation 

```
brew tap ollie-galbraith/jumpshell
brew install jumpshell
```

## Source Code

The source code for Jumpshell is located at [https://github.com/ollie-galbraith/jumpshell](https://github.com/ollie-galbraith/homebrew-jumpshell)
